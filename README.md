# MONOLITH website

Static site (no build step). Hosted on GitHub Pages: https://gaged881-design.github.io/monolith/

Everything you may need to change is in `config.js`: Whop plan ids, prices, the download link,
the Toolbox checksum and version, support email, refund policy. Edit, commit, push; Pages updates
in about a minute.

To show it inside your whop: add Whop's "Website Embed" app and paste the address above.
